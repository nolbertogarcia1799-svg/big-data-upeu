# Producto Unidad I - Online Shoppers

Proyecto UPeU Ciencia de Datos e IA Aplicada. Dataset: UCI Online Shoppers Purchasing Intention (DOI: https://doi.org/10.24432/C5F88Q).

Este subdirectorio contiene el codigo fuente reproducible. El paquete completo con datos, diccionario de variables, graficos, resultados y guia se entrego en ZIP dentro de la conversacion ChatGPT. Para reproducir, coloque `online_shoppers_intention.csv` en `data/raw/`, ejecute `Rscript scripts/01_preparacion.R` desde la raiz de este subdirectorio y renderice `reports/reporte_unidad_1.qmd` con Quarto.

**Estado:** la publicacion de los datos y anexos binarios, la ejecucion de R/Quarto y la etiqueta `v1.0-unidad1` aun requieren verificacion. No confundir esta publicacion parcial con entrega final.
